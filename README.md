# END ERA eSports Website V2

Standalone mobile-first tournament website prototype.

## Demo Admin
Email: admin@endera.gg

## V2 features
- Admin login guard
- Create tournaments from admin panel
- Create/publish groups with room ID/password
- Local browser storage for demo data
- Group room opens published group
- Tournament filters
- Results/leaderboard
- Mobile responsive UI

## Important
This is still a client-side demo. localStorage is NOT a real secure database and should not be used for real payments, credentials, or production admin security.

## Next production step
Connect Google Apps Script + Google Sheets (or Supabase) for real multi-user accounts, database, registrations, teams, payments, and secure admin APIs.
